# hackathon-demo-annualreels

發票年度回顧的 IG Reels 分鏡 demo —— 把個人消費紀錄做成 Spotify Wrapped 式的
15 秒直式短影音。

## 看 demo

直接用瀏覽器開 `index.html`，或起一個本機 server：

```bash
python3 -m http.server 8000
# 然後開 http://localhost:8000
```

左邊是 9:16 播放器（會自動播，點畫面左右兩側跳幕），右邊是每一幕的
文案模板與取數欄位。

## 這支影片的結構

15 秒六幕，每幕只講一件事，切點對齊約 96 BPM 的每四拍：

| 幕 | 秒數 | 內容 |
|---|---|---|
| 1 | 0.0–2.6 | 開場總量：發票張數、店家數、品項件數 |
| 2 | 2.6–5.0 | 本命商品：一年買最多次的單品 |
| 3 | 5.0–7.6 | PR 值徽章：在買過的人裡排前 N% |
| 4 | 7.6–10.0 | 主場門市：具體到單一門市 |
| 5 | 10.0–12.5 | 年度戰友：12 個月每月都出現的品項 |
| 6 | 12.5–15.0 | 消費人格與收尾 |

## 產製規格

- 1080 × 1920（9:16），30fps
- 安全區：上 13%、下 22%（頁面上有「安全區」按鈕可切換輔助線）
- 字級下限 36px（換算 1080 寬）
- 這份 HTML 就是可用的動畫版型，1080×1920 錄螢幕即成品；
  批次生成走同一套：換資料重跑、用 Playwright 錄製

## 技術

單一 HTML 檔，無外部相依、無建置步驟。純 CSS 動畫 + 一段控制幕次的 vanilla JS。
支援 `prefers-reduced-motion`。

## 注意

**畫面上所有數字與品名都是示意，不是任何真實個人的消費紀錄。**
品名只作為排版長度的範例。
